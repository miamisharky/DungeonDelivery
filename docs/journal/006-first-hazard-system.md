# First Hazard System

## Goal

Add the first danger object to the game.

## What Did I Learn?

Hazards can use Area2D collision detection just like collectibles and recyclers.

Time can be used as both a countdown and a health-like resource.

Cooldowns are important to prevent repeated damage every frame.

## Why Does It Matter?

The game now has risk.

The player must steer carefully instead of simply flying straight to the recycler.
