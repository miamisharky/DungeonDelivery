# Design Pillars

## Pillar 1: Physics Feels Fun

The rocket should feel satisfying to steer, accelerate, drift, and recover.

## Pillar 2: Build Choices Matter

Rocket parts should create meaningful tradeoffs:
speed, handling, cargo, fuel, durability, and boost.

## Pillar 3: Short Runs, Long Progression

Individual missions should be quick, but upgrades should create long-term motivation.

## Pillar 4: Cleanup Feels Rewarding

The player should visibly improve orbital zones and planets over time.

## Pillar 5: Complete Before Complex

Every new system must support the playable loop before expanding.
